# Mountain Kings

Jeu coop sur téléphone : un village nain chacun dans la même vallée, des raids solo contre les camps orques, et des raids à deux en direct.

- `docs/` : le site du jeu, prêt à publier (GitHub Pages depuis le dossier `docs`, Netlify ou Firebase Hosting).
- `database.rules.json` : les règles de sécurité de la base temps réel Firebase.
- `firebase.json` : réglages pour publier avec Firebase Hosting (`firebase deploy`).

Le jeu s'installe comme une appli depuis le navigateur (menu « Ajouter à l'écran d'accueil » ou bouton « Installer l'appli » dans le jeu). Chaque nouvelle version publiée arrive toute seule au lancement suivant.
